assert.notEqual(actual, expected[, message])
Verifica que actual != expected (con comparación no estricta, es decir, usando !=).
Si sí son iguales (aunque sea por coerción de tipos), lanza un AssertionError.

assert.ok(value[, message])
Verifica que value sea truthy.
Si el valor es falsy (como false, 0, '', null, undefined, o NaN), lanza un AssertionError.

assert.rejects(asyncFn[, error][, message])
Verifica que una función asíncrona o promesa rechace.
Y si se pasa el argumento error, también verifica que el motivo del rechazo coincida con un patrón o clase de error.
Si la promesa no es rechazada, o no coincide con el error esperado, lanza un AssertionError.

asyncFn: una función async o promesa que debe rechazar.
error (opcional): patrón de error que debe cumplir (puede ser un RegExp, función, objeto, clase de error).
message (opcional): mensaje personalizado si la aserción falla.

assert.strictEqual(actual, expected[, message])
Verifica que actual === expected.
Sí, usa comparación estricta, sin coerción de tipos (como el triple igual === en JavaScript).
Si no son estrictamente iguales, lanza un AssertionError.

assert.throws(fn[, error][, message])
Verifica que una función síncrona (fn) lance una excepción (o sea, que haga throw).
También puede verificar que el error lanzado coincida con un tipo específico, mensaje, expresión regular o propiedades.
Si la función no lanza nada, o lanza algo que no coincide con el error esperado, lanza un AssertionError.
fn: función síncrona que debe lanzar un error.
error (opcional): patrón de error esperado (RegExp, clase, objeto, o función validadora).
message (opcional): mensaje personalizado si la aserción falla.
assert.throws() no funciona con funciones async o promesas.
Para eso debes usar:  assert.rejects().

Buffer:
El módulo Buffer en Node.js proporciona una manera eficiente de trabajar con secuencias de bytes sin procesar (datos binarios). Los objetos Buffer son instancias de una clase global que almacenan arrays de enteros de 8 bits (bytes).
Propósito principal:
Manipular datos binarios directamente.

Interactuar con flujos de datos (streams), archivos, sockets de red y protocolos binarios.

Convertir entre diferentes codificaciones (UTF-8, ASCII, Base64, Hex, etc.).

Ofrecer una interfaz similar a un array para manejar bytes individuales.


Buffers and character encodings
Node.js usa Buffer para almacenar los bytes y codificaciones para convertir esos bytes en texto y viceversa.
Codificaciones compatibles en Node.js

'utf8'	Predeterminada, soporte completo para Unicode
'ascii'	Solo caracteres del 0 al 127
'utf16le'	UTF-16 little endian
'base64'	Codificación de texto para bytes binarios
'hex'	Representación hexadecimal
'latin1' / 'binary'	ISO-8859-1 (bytes del 0 al 255)

Si usás la codificación incorrecta, el texto se corrompe.
ascii y latin1 no manejan bien caracteres especiales (ñ, á, emojis).
Para la mayoría de los casos, usa utf8.

Buffers and TypedArrays
Un TypedArray es como un array normal de JavaScript, pero más eficiente, rápido y con tipado estricto.
No guarda cualquier cosa: solo números (enteros, flotantes, etc.) de tamaño fijo.

Internamente, Buffer es una extensión de Uint8Array, que a su vez es un tipo específico de TypedArray.
uint8Array es un tipo de typedArray de 8 bits sin signo (0–255).
Entonces Buffer es parte de un uint8Array que a su vez es un tipo de typedArray.

new buffer.Blob([sources[, options]])
Este constructor crea una nueva instancia de la clase Blob en Node.js, directamente desde el módulo buffer.
sources (Array) – obligatorio
Una lista de partes que componen el contenido del blob.
Pueden ser:
Buffer
ArrayBuffer
Blob
TypedArray
DataView
string
Básicamente, cualquier cosa que represente datos binarios o texto.

(objeto) – opcional
type	Tipo MIME (como 'text/plain', 'image/png', etc.). Sirve para describir el contenido del blob.
endings	"transparent" (por defecto) o "native" – cómo tratar saltos de línea \n. Solo afecta strings.

Métodos útiles de Blob
blob.size	Tamaño total del blob (en bytes).
blob.type	Tipo MIME del contenido.
blob.text()	Devuelve una promesa con el contenido como string UTF-8.
blob.arrayBuffer()	Devuelve una promesa con un ArrayBuffer del contenido.
blob.bytes()	(Desde v20.16.0) Devuelve una promesa con los bytes como Uint8Array.
blob.slice(start, end, type)	Crea un nuevo Blob con un subconjunto del original.
blob.stream()	Devuelve un ReadableStream para leer los datos.

Uso típico
Simular archivos (como en navegadores)
Enviar/recibir binarios grandes
Compatibilidad con fetch, stream, etc.

Buffer.alloc(size[, fill[, encoding]])
Crea un buffer inicializado.

Llena con 0 por defecto.

Buffer.allocUnsafe(size)
Más rápido, pero NO inicializa la memoria.

Puede contener datos sensibles residuales.

Inicialízalo manualmente con .fill(0) si hace falta.

Buffer.allocUnsafeSlow(size)
Igual que allocUnsafe, pero no usa el pool interno.

Ideal para mantener segmentos de memoria pequeños por tiempo indefinido.

 Buffer.byteLength(string[, encoding])
Retorna la cantidad de bytes que ocupa un string según su encoding.

 No confundir con string.length.

 Buffer.compare(buf1, buf2)
Compara dos buffers lexicográficamente.

Útil para ordenar listas de buffers.

 Buffer.concat(list[, totalLength])
Une varios buffers en uno solo.

totalLength es opcional, pero recomendable para rendimiento.

 Buffer.copyBytesFrom(view[, offset[, length]])
Copia datos desde un TypedArray como Uint8Array, Uint16Array, etc., hacia un nuevo buffer.

 Requiere Node.js 18.16+ o 19.8+
 Buffer.from(array)
Crea un buffer desde un array de bytes [0–255].

Seguridad y Rendimiento
Usa Buffer.alloc cuando necesites seguridad (contenido limpio).
Usa Buffer.allocUnsafe cuando necesites velocidad, pero entiendas el riesgo.

Buffer.from(arrayBuffer[, byteOffset[, length]])
Crea un `Buffer` que comparte la misma memoria subyacente con el `ArrayBuffer` proporcionado. No copia los datos. Puede especificarse un desplazamiento inicial (`byteOffset`) y una longitud.

Buffer.from(buffer)
Crea un nuevo `Buffer` copiando el contenido del `Buffer` o `Uint8Array` dado. No comparte memoria.

Buffer.from(object[, offsetOrEncoding[, length]])
Convierte un objeto que implemente `valueOf()` o `Symbol.toPrimitive()` a un `Buffer`. El valor retornado por estos métodos se pasa a `Buffer.from()`.

Buffer.from(string[, encoding])
Crea un `Buffer` a partir de una cadena de texto usando la codificación especificada. Si no se indica, se usa `'utf8'` por defecto.

Buffer.isBuffer(obj)`
Devuelve `true` si el objeto dado es un `Buffer`. En caso contrario, devuelve `false`.

Buffer.isEncoding(encoding)

Devuelve `true` si el argumento es el nombre de una codificación soportada. De lo contrario, devuelve `false`.

Buffer.poolSize
Propiedad estática que indica el tamaño del pool interno de `Buffer` en bytes. Valor predeterminado: 8192. Puede modificarse para ajustar el comportamiento del sistema de memoria interna.

buf[index] 
buf[index] es la forma en que accedes directamente a un byte específico dentro de un objeto Buffer en Node.js.
El índice (index) es un número entero que representa la posición del byte dentro del buffer, comenzando desde 0.
El valor que se obtiene o asigna es un número entre 0 y 255 (es decir, un byte).
Este acceso es similar a cómo se accede a elementos de un array en JavaScript.
Si accedes a un índice fuera de rango (index < 0 o index >= buf.length), el resultado será undefined.
Puedes leer o modificar directamente los bytes del buffer con este acceso.
